Canvas Companion Settings

Phase 0 scaffold — fields are visual only

Phase 0: this page is a layout shell so you can inspect the settings surface. Connect / token / LLM / reminders are wired in later phases. Nothing is saved yet.

Canvas connection

On first run (Phase 1) this requests a host permission for that origin only — not every Instructure school.

API token fallback

Default auth uses your existing Canvas session cookies. Paste a token only if cookie calls return 401/403 (some SSO setups). Stored in chrome.storage.local, never logged.

Duey (LLM)

Read only by the background worker. Never exposed to Canvas pages.

Reminders

Google Calendar (no extra sync code)

Canvas already publishes an ICS feed at Account → Settings → Calendar Feed (https://<school>.instructure.com/feeds/calendars/user_XXXX.ics). Google Calendar can subscribe to that URL natively. Phase 7 will surface a copy/paste helper. This extension will not scrape or guess your feed URL.
